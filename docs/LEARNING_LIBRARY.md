# 일본어 학습 메뉴·손글씨 예시 첫 구현

이 기능은 **학습 메뉴**이며 인식 모델의 문자 클래스나 학습 데이터를 재분류하지 않습니다.
기존 네이티브 ES module, 실시간 코치, 1단계 따라쓰기·2단계 암기쓰기 구조에 연결했습니다.

화면은 기본으로 접힌 상단 **학습·설정** 바와 쓰기 캔버스·필수 동작·피드백으로 구성합니다.
학습 분류, 문자 선택, 글꼴·자형, 쓰기 단계, 서버 상태, 기록·출처는 바를 열면 볼 수 있습니다.
설정을 고른 뒤 **선택 완료 · 쓰기**로 캔버스에 돌아옵니다. 빠른 문자와 검색 결과 확정은
즉시 쓰기로 돌아옵니다. 접힌 영역은 `hidden`·`inert`로 포커스에서 제외하고,
닫기/Escape는 상단 바, 선택 완료는 캔버스로 포커스를 이동합니다. 문자 선택 대화상자는
독립적으로 Escape·Tab 순환·닫은 뒤 포커스 복귀를 처리합니다. 단순 열기/닫기는 필기와
시도 상태를 바꾸지 않습니다.

## 데이터 범위와 근거

- 현대 기본 히라가나 46자와 가타카나 46자.
- 인사·감사, 식당·주문, 길 찾기, 쇼핑 각각 3개: 총 12개 자체 작성 단어·표현.
- N5~N1 각 2개: 총 10개 어휘와 그 구성 문자 연습. 읽기·한국어 뜻·항목별 선정 이유 포함.
- 메뉴에 등장하는 문자와 기존 빠른 선택·자형 비교 예시를 합쳐 125개 기본 템플릿을 정적 자산으로 제공.
- 木의 대체 연습 자형 1개, 令의 인쇄형 비교 예시 1개.

JLPT의 [공식 FAQ](https://www.jlpt.jp/faq/) 4번 영역은
어휘·한자·문법 항목을 나열한 출제기준을 공개하지 않는 이유를 설명합니다.
[N1~N5 능력 설명](https://www.jlpt.jp/e/about/levelsummary.html)을 일반적인
학습 목표로 참고하고 **소수의 편집자 추정 예시**를 골랐습니다. 개별 단어 급수에 대한
공식 확인이나 완전한 목록이 아닙니다. 어휘의 구성 한자에 독립적인 급수를 배정하지 않고,
초등학교 학년 또는 구 JLPT 등급을 N1~N5로 일괄 매핑하지 않습니다.

`web/learning.js`가 메뉴·문구·급수 추정 근거의 원본입니다. 자료를 늘릴 때도 항목마다
읽기·뜻·출처·선정 근거를 기록해야 합니다. 상급 급수의 교육적 타당성과 예시 표현은
일본어 교사의 추가 검토 대상입니다. 탁음·반탁음·요음 전체 메뉴, 독해·청해·문법 문제,
공식 시험 범위 전체, 복습 스케줄은 아직 포함하지 않았습니다.

## 표시, 획순 연습, 채점의 구분

`web/learning-panel.js`의 왼쪽 예시는 Klee One / Zen Kurenaido / Yomogi를 선택합니다.
글꼴 윤곽은 참고용이며 획순을 추정하지 않습니다. TTF는 그대로 보존하고 라이선스와
해시·cmap을 `web/fonts/`에 동봉했습니다. 세 글꼴 모두 이 125자를 포함하는지 테스트합니다.
큰 글자 옆에는 **현재 연습 경로**를 따로 보여 줍니다.

Canvas의 따라쓰기 선은 KanjiVG의 원래 베지어 경로를 `Path2D`로 그립니다.
코치·기존 모델은 원래의 12점 표현을 그대로 사용합니다. 곡선과 좌표의 정규화
scale/offset을 같은 12점 경계에서 계산하고 전체 팩의 좌표 일치를 검사합니다.
암기쓰기의 위치·크기 맞춤은 기존 코드를 유지합니다.
`GET /template/{char}`에는 optional `display` 필드만 추가했고 기존 `char`, `strokes`,
기본 파일 선택과 `/score` 계약은 유지했습니다.

## 자형 검수와 보수적인 허용 목록

`configs/template-variants.json`은 검수한 파일과 원본 SHA-256, 획수·획 종류·순서,
용도와 근거를 명시합니다. `-Kaisho`, `-Insatsu`나 내부 `kvg:variant`만으로 자동 승인하지 않습니다.
현재 `scorer/data.py`의 재학습 문자 집합은 바꾸지 않았습니다.

| 문자 | 비교한 원본 | 관찰한 차이 | 제공 범위 |
|---|---|---|---|
| 木 | 06728.svg / 06728-Kaisho.svg | 같은 4획, 가로→세로→왼쪽 내림→오른쪽 내림. 두 번째 획 끝이 정지/왼쪽 위 올림으로 다름. 나머지 곡선의 세부 모양도 다름. | 명시적으로 선택한 경로로 로컬 따라쓰기·암기쓰기·획 교정 |
| 令 | 04ee4.svg / 04ee4-Insatsu.svg | 모두 5획. 앞 2획은 같지만 3획이 점/가로, 4·5획이 マ 모양/卩 모양으로 다름. | Insatsu는 모양 비교만; 연습 선택지에 넣지 않음 |

원본 XML의 경로·순서를 읽고 실제 곡선 렌더를 나란히 비교했습니다. 이 검수는
자료·경로 검토이며 사람 필기 전체의 정답 판정, 전문가 인증, 새 모델 보정이 아닙니다.
[문화청의 자형 지침](https://www.bunka.go.jp/seisaku/kokugo_nihongo/kokugo_shisaku/joyokanjihyo_sakuin/index.html)은
손글씨 예시가 유일한 표준 자형이 아님을 설명합니다. 문서 그림은 복제하지 않았고,
이 앱의 폰트를 정부 지정 서체로 표현하지 않습니다.

대체 木를 고르면 기본형만 아는 `/coach/stroke`, `/score`, 교사 API 호출을 차단합니다.
기존 서버 필기 기록 계약에는 자형 ID가 없으므로 대체 자형 기록은 브라우저에만 남기고
`template_variant`를 붙입니다. 자형·문자·학습 항목·쓰기 단계를 바꾸면 기존 요청을
무효화하고 새 시도를 시작합니다. 글꼴 선택은 진행 중인 필기와 채점 상태를 보존합니다.
모든 자형 중 최고 점수를 취하는 방식이나 무조건 정답 처리는 하지 않습니다.

## 재생성과 확인

```bash
python scripts/build_learning_assets.py
python scripts/audit_handwriting_fonts.py  # 개발 도구 fontTools 필요
python -m pytest -q
node --test web/tests/*.test.mjs
python -m uvicorn scorer.server:app --host 127.0.0.1 --port 8000
```

팩 생성은 Node와 기존 NumPy 파서를 사용합니다. 라이선스는 `web/data/LEARNING-NOTICE.md`,
폰트는 `web/fonts/NOTICE.md`를 참고하세요. 웹 배포에는 `web/fonts/`, `web/data/learning-practice.json`,
새 모듈과 import map을 함께 포함해야 합니다. 모델 서버 없이 정적 앱을 연 경우에도
포함된 125자에서는 로컬 코치가 동작합니다. 사이트 자산 자체의 네트워크 단절에 대비하는
PWA 캐싱은 이 변경의 범위가 아닙니다.

검증하지 않은 범위: 실제 iPad/Apple Pencil, GPU·Chandra/hybrid 실채점, RunPod,
배포된 Edge 경유, 실제 사람 필기의 자형 허용률. 재학습·유료 API·원격 배포를 수행하지 않습니다.
